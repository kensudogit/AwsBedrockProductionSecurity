# リリース前検証

- [ ] 無署名、改ざん、期限切れ、別issuer、別client_id、ID token、権限不足を拒否
- [ ] JWKS取得失敗時はfail-closed（認証成功にしない）
- [ ] 別テナント文書・会話・ベクトル検索結果を取得不可
- [ ] CORS/CSRF/SSRF/アップロード制限、URL許可リスト、HTTPタイムアウトを検証
- [ ] ツール呼び出しのサーバー側承認、二重実行防止、監査を検証
- [ ] IAMポリシーとシークレットの露出を検査
- [ ] 429、モデル障害、リトライ、コスト上限の挙動を検証
- [ ] CIで `pytest`、`pip-audit`、`bandit`、コンテナスキャン等を実行
- [ ] 機密ログ、監査ログ保持、鍵ローテーション、復旧訓練を確認
